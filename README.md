# Amanah Travel - Vue + Express

## Struktur
- frontend: Vue 3 + Vite + Bootstrap 5
- backend: Express.js
- API: GET /api/packages

## Menjalankan

Terminal 1:
cd backend
npm install
npm run dev

Terminal 2:
cd frontend
npm install
npm run dev

Frontend: http://localhost:5173
Backend: http://localhost:3000
